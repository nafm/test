# Java 21 TUI Application

Boilerplate d application console / TUI en Java 21 standard avec Maven.

## Pre-requis
- Java 21 (JDK 21 LTS)
- Maven 3.9+

## Compilation et Tests
```bash
mvn clean test
```

## Generation du JAR et Execution
```bash
mvn clean package
java -jar target/tui-app-1.0.0-SNAPSHOT.jar
```
